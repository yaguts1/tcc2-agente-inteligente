PASSO 1: Backend (FastAPI) - 1 hora
─────────────────────────────────────

Arquivo: interface/api.py

Adicionar após linha 100 (após ConnectionManager):

```python
@router.websocket("/ws/eventos")
async def websocket_eventos_endpoint(websocket: WebSocket):
    """WebSocket para ingesto de eventos ESP32 real-time."""
    await manager.connect(websocket)
    
    try:
        # 1. Receber autenticação
        auth_msg = await websocket.receive_text()
        auth = json.loads(auth_msg)
        device_id = auth.get("device_id")
        cama_id = auth.get("cama_id")
        
        # 2. Registrar dispositivo
        dispositivo = await registrar_device(device_id, cama_id)
        
        # 3. Loop de eventos
        while True:
            data = await websocket.receive_text()
            evento = json.loads(data)
            
            # Processar
            resultado = await inserir_eventos(
                device_id=evento.get("device_id"),
                eventos=[evento]
            )
            
            # Enviar ACK
            await websocket.send_json({
                "status": "ok",
                "seq": evento.get("seq")
            })
            
    except WebSocketDisconnect:
        manager.disconnect(websocket)
```

Testes:
$ pytest tests/test_websocket.py -v


PASSO 2: ESP32 (C++) - 1.5 horas
──────────────────────────────────

Arquivo: firmware/esp32_replay/esp32_replay.ino

1. Adicionar na sessão #include:
```cpp
#include <WebSocketsClient.h>
```

2. Adicionar variável global:
```cpp
WebSocketsClient webSocket;
String g_server_host = "192.168.0.67";
uint16_t g_server_port = 8000;
```

3. Adicionar função callback:
```cpp
void webSocketEvent(WStype_t type, uint8_t *payload, size_t length) {
  switch(type) {
    case WStype_CONNECTED:
      {
        // Enviar autenticação
        String auth = "{\"device_id\":\"" + g_config.deviceId + 
                     "\",\"cama_id\":\"" + g_config.camaId + "\"}";
        webSocket.sendTXT(auth);
        atualizarEstado(ReplayState::ENVIANDO);
      }
      break;
      
    case WStype_TEXT:
      {
        // Receber ACK ou comando
        String msg((const char*)payload);
        if (msg.indexOf("\"status\":\"ok\"") >= 0) {
          g_eventoDisponivel = false;
        }
      }
      break;
      
    case WStype_DISCONNECTED:
      atualizarEstado(ReplayState::OCIOSO);
      break;
  }
}
```

4. Em setup():
```cpp
webSocket.begin(g_server_host.c_str(), g_server_port, "/ws/eventos");
webSocket.onEvent(webSocketEvent);
webSocket.setReconnectInterval(5000);
```

5. Em loop():
```cpp
webSocket.loop();  // ← Adicionar antes de processarReplay()
```

6. Modificar enviarEvento():
```cpp
bool enviarEvento(const EventoReplay &evento) {
  if (!webSocket.isConnected()) {
    return false;
  }
  webSocket.sendTXT(evento.payload);
  g_status.totalEnviados++;
  return true;
}
```

Testes:
- Conectar ESP32
- Enviar evento
- Verificar ACK em log
